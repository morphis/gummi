# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull
requests or discussions.

Report them privately through GitHub's private vulnerability reporting:
[open a security advisory](https://github.com/morphis/gummi/security/advisories/new).

Include what you can of:

- the affected version or commit,
- what an attacker can do and under which conditions,
- steps to reproduce, or a proof of concept.

You will get an acknowledgement on the advisory, and the fix and its
disclosure are coordinated there.

## Supported versions

Fixes land on `main`; there are no maintained release branches.
